LiveCaptionN turns your Android phone into a real-time speech-to-text captioning and translation tool that floats on top of any app — live captions and subtitles for videos, calls, meetings, and everyday conversations. It listens via mic or app audio, transcribes word-by-word with low latency, translates into your chosen language, and renders a floating, draggable caption window.

Perfect for watching foreign-language videos, following meetings, language learning, or hearing accessibility — subtitles that work across all apps.

Both halves of the pipeline run on-device by default:
• Streaming Vosk speech recognition — continuous low-latency transcription
• Google ML Kit on-device translation — ~59 languages, offline after download
No account required. Zero server dependency for on-device mode.

FEATURES
• Floating caption overlay on top of any app: drag, pinch-resize, pause, minimize
• Mic or system audio capture (via MediaProjection)
• Built-in downloader for on-device Vosk speech models
• On-device translation via Google ML Kit, plus optional LibreTranslate backend
• Interface translation: translate the entire app UI into 59 languages
• Searchable transcript history, text export, and preset profiles
• Automatic update notifications via GitHub Releases

SYSTEM REQUIREMENTS & COMPATIBILITY CHECK
LiveCaptionN includes an automatic hardware compatibility check at launch:

• On-Device AI Mode (Streaming Vosk STT + ML Kit Translation):
  - Minimum Requirements: 2.5 GB RAM, 4 CPU cores, 350 MB free storage.
  - Recommended: 4 GB+ RAM, 64-bit multi-core CPU, 1.5 GB+ free storage (for Large models).
  - Compatibility Guard: Devices below 2.5 GB RAM or 4 cores are automatically switched to Remote mode to protect device stability. Devices with 2.5–3.8 GB RAM receive a performance advisory with lightweight model options.

• Remote Self-Hosted Mode (OpenAI Whisper ASR + LibreTranslate):
  - Works on any Android 9.0+ device (1.5 GB+ RAM) connected via Wi-Fi to your local PC/server.
  - Zero mobile CPU/battery drain, maximum transcription accuracy, and 100% LAN privacy.
  - In-app interactive tutorial with dedicated video guide, TTS voice narration, synchronized captions, and complete web documentation.

PRIVACY & PERMISSIONS
• Runs on-device: your audio and captions stay private on your phone or local network.
• Android 9.0 (API 28) or newer (Android 10+ for system audio).
• Requires Microphone and 'Display over other apps' permissions.
• Open source: built transparently via GitHub Actions.
